**As of September 1, 2026**, the ``.stl`` files here are **Revision 2**, designed for the Revision 2 board and with a cut-out on the side that makes the debug pins accessible from outside the case. Revision 1 files are archived in [``[old] Revision 1``](https://github.com/OpenDosimeter/OpenDosimeter/tree/main/case/%5Bold%5D%20Revision%201).

The case (enclosure) for the OpenDosimeter has been designed using [Onshape](https://www.onshape.com/en/), a free CAD program in the web browser.

The .STL files here can be downloaded for 3D printing using any 3D printer with accompanying slicer.

For access to the design files in Onshape, see here:  [OpenDosimeter case (top + bottom)](https://cad.onshape.com/documents/07a403b276888ec58c58bf4a/w/17070c312469849a165ab203/e/cd9056bedca93ea5562429ae?renderMode=0&uiState=6a96926ceb8744dc631091d0)
